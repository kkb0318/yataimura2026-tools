# からだで学ぶ プログラミングワールド - 入口チラシ

コミュニティイベント「からだで学ぶ プログラミングワールド」の会場入口に掲示する A3 看板チラシを PDF で生成するスクリプトです。

宝探し風のパーチメント調デザインで、以下の情報を掲載しています。

- イベントタイトル・キャッチコピー
- 体験できるゲーム（にんげんロボットゲーム / ロジックたからさがし）
- 開催時間

## 必要なもの

- Python 3.10+
- [uv](https://docs.astral.sh/uv/)

## 使い方

```bash
uv run programming_world_poster.py
```

カレントディレクトリに `programming_world_poster.pdf` が生成されます。

## フォントについて

スクリプトは以下の順序で日本語フォントを探します。

1. システムにインストール済みの IPA ゴシック（Linux `fonts-ipafont-gothic` パッケージ等）
2. `~/.fonts/ipagp.ttf` や `~/Library/Fonts/ipagp.ttf` に手動配置したフォント
3. **見つからない場合**: IPAexゴシックを自動ダウンロードして `~/.cache/fonts/` にキャッシュ

初回実行時のみダウンロードが発生し、2回目以降はキャッシュが使われます。

## カスタマイズ

スクリプト内の定数を編集することで、文言・色・レイアウトを変更できます。

| 項目 | 変更箇所 |
|---|---|
| 開催時間 | `create_poster()` 内の `11:00 〜 13:00` 等 |
| ゲーム名・説明 | `draw_game_block()` の呼び出し引数 |
| 配色 | 冒頭のカラーパレット定数 |
